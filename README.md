# Retail Sales Data Analysis — UK Coffee Retail Dataset

## What this is
Excel-based data cleaning and analysis project on a UK coffee retail dataset (5,000+ records).

## Problem
The raw dataset contained duplicates, missing values, typos, and formatting inconsistencies — unusable for analysis in its original state.

## What I did
- Cleaned and transformed the dataset: removed duplicates, handled blank/missing cells, standardized formatting
- Used SUMIF, SUMIFS, COUNTIF, COUNTIFS to analyze business performance
- Structured the cleaned data into a formatted table
- Built a dashboard to present key business insights

## Tools
Excel
